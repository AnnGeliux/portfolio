## Lo que cubre

Curso de **AMD AI Academy** sobre los fundamentos de los **agentes de IA**:
qué es un agente, cómo razona y actúa (bucle ReAct), y cómo se construye uno
usando el **Model Context Protocol (MCP)** para conectar herramientas e
**inferencia open-source** en lugar de depender de un único proveedor cerrado.

## Lo que aprendí

- **Anatomía de un agente:** percepción, razonamiento y acción; el bucle
  ReAct (razonar → actuar → observar) como patrón central.
- **MCP como capa de herramientas:** cómo el protocolo permite a un agente
  invocar herramientas externas de forma estandarizada.
- **Inferencia open-source:** ejecutar el cerebro del agente con modelos
  abiertos, sin amarrarse a una API propietaria.
- **Composición:** cómo estos bloques (agente + herramientas + modelo) forman
  sistemas útiles de punta a punta.

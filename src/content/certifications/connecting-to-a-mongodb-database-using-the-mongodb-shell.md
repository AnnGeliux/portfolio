## Lo que cubre

Tercer curso del learning path **Introduction to MongoDB** de MongoDB
Academy. El MongoDB Shell (mongosh) es la herramienta para hablar
directamente con la base de datos: este curso lo cubre de conexión a
consultas.

## Lo que aprendí

- **Conexión con mongosh:** construir la connection string, conectarse a
  un clúster de Atlas y autenticarse como usuario de base de datos.
- **CRUD en la terminal:** insertar, consultar, actualizar y borrar
  documentos directamente desde el shell.
- **Filtros y operadores:** queries con operadores de comparación y
  lógicos, y cómo se combinan para afinar resultados.
- **Proyecciones:** pedir solo los campos necesarios y leer documentos
  grandes sin traer todo el documento.

## Por qué importa

El shell es la red de seguridad: cuando un driver o un ORM falla,
mongosh es la forma de verificar qué hay realmente en la base de datos.
Dominarlo hace que depurar Prisma + MongoDB deje de ser adivinar.

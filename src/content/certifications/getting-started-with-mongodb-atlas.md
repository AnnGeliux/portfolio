## Lo que cubre

Primer curso del learning path **Introduction to MongoDB** de MongoDB
Academy. Recorre MongoDB Atlas de punta a punta: qué es un clúster, cómo
se despliega en la nube y cómo se configura para poder trabajar con él
de forma segura.

## Lo que aprendí

- **Clústeres de Atlas:** crear y dimensionar un clúster (free tier
  incluido), entender la arquitectura de replica sets que Atlas gestiona
  por debajo.
- **Seguridad de acceso:** configurar usuarios de base de datos y la IP
  allowlist de red para controlar quién puede conectarse.
- **Carga de datos:** poblar el clúster con datos de ejemplo y explorar
  las colecciones desde la interfaz de Atlas.
- **Atlas como plataforma:** conocer las piezas más allá de la base de
  datos — búsqueda, monitoreo y las herramientas que rodean al clúster.

## Por qué importa

Atlas es la vía más rápida para tener una base de datos documental en
producción sin administrar infraestructura. Los proyectos que construyo
con stack JS (NestJS, Prisma) necesitan un datastore administrado: este
curso cubre exactamente ese eslabón del despliegue.
